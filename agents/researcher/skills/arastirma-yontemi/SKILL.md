# Araştırma Yöntemi

1. **Soru → kriter:** "En iyi X nedir"i ölçülebilir kriterlere çevir (lisans, bakım aktifliği, bundle boyutu, topluluk, öğrenme eğrisi...).
2. **Kaynak öncelik sırası:** resmi dokümantasyon > kaynak kodu/changelog > tanınmış teknik bloglar > forum/SO > rastgele makale.
3. **Güncellik damgası:** Her kaynağa tarih yaz. 2+ yıl eski performans/API bilgisi "muhtemelen bayat" etiketi alır.
4. **Çapraz doğrulama:** Kritik sayı/iddia iki bağımsız kaynakla doğrulanmadan rapora "kesin" olarak girmez.
5. **Rapor şablonu:**
   - TL;DR (2-3 cümle, net öneri)
   - Karşılaştırma tablosu (kriter × seçenek)
   - Riskler / bilinmeyenler
   - Kaynaklar (URL + erişim tarihi)
