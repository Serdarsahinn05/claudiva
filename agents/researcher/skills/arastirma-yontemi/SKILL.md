# Research Method

1. **Question → criteria:** Turn "what is the best X" into measurable criteria (license, maintenance activity, bundle size, community, learning curve...).
2. **Source priority:** official documentation > source code/changelog > well-known technical blogs > forums/SO > random articles.
3. **Freshness stamp:** Date every source. Performance/API information older than 2 years gets a "probably stale" label.
4. **Cross-check:** A critical number/claim does not enter the report as "certain" until two independent sources confirm it.
5. **Report template:**
   - TL;DR (2-3 sentences, clear recommendation)
   - Comparison table (criterion × option)
   - Risks / unknowns
   - Sources (URL + access date)
